Song Radio

Song Radio builds a playlist around a single song. You pick a source track from your library, decide how similar tracks are found, and then shape the final mix with quality, diversity, and refresh settings.

Create a playlist in 4 steps
  1. 1 Search and select a source track. Search your library by title, artist, or album and pick the song the radio should be built around. If the track has no MusicBrainz recording ID in your metadata, you will be asked to enter one.
  2. 2 Choose how similar tracks are found. Use ListenBrainz similarity, the Navidrome similar-tracks feature, or both. Then adjust the algorithm, minimum score, and expansion rounds if you want a narrower or wider pool.
  3. 3 Click "Find Similar Tracks". This builds the candidate pool and shows how many matching tracks were found in your library. You can choose another track at any time to start over.
  4. 4 Choose the final playlist shape. Set the year range, minimum quality, playlist length, diversity limits, and refresh frequency, then create the playlist.
What each option changes

Source track

Sets the center of the radio. Every similar track is derived from this song, so a well-known track with good metadata usually returns better results.

MusicBrainz recording ID fallback

Only shown when the selected track has no recording ID in your library metadata. It is needed to look up similar recordings on ListenBrainz. It does not change which tracks are selected for the playlist.

Navidrome similar-tracks

Only available with Navidrome. Adds tracks that the server itself considers similar to the source track. It works without MusicBrainz IDs and can widen the candidate pool or act as a fallback when ListenBrainz finds little.

ListenBrainz similarity

When enabled, MagicLists asks the ListenBrainz API for recordings similar to your source track and matches them against your library. When disabled, the pool is built only from the other enabled sources.

ListenBrainz algorithm

The algorithm controls how similarity is measured. The exact algorithm workflow is known by ListenBrainz labs, but the names of the selectable Options name a timespan with a algorithm described by a single Word. Try out what works best for you.

ListenBrainz minimum similarity

The minimum score controls how broad or narrow the pool becomes: lower scores include more distant matches, higher scores stay closer to the source track but return fewer results.

Expansion rounds

This Value specifies the maximum number of Search rounds for Listenbrainz. After each search round, the search continues from one of the newly found tracks to explore further along the similarity chain. More rounds build a larger and more adventurous pool, but the results drift further from the original song and the search takes longer.

Find similar tracks

Builds the candidate pool using the settings above and reports how many tracks from your library were matched. A small pool means the playlist may be short or repetitive, so consider lowering the minimum score or adding more expansion rounds.

Year range and minimum quality

Year range limits the eras in the candidate pool. Minimum quality filters out lower-bitrate or lower-bit-depth files before curation. This can cause a smaller AI curation pool when only lower-quality tracks are available, resulting in poor playlist quality or variety.

Diversity limits

Controls how many tracks can come from the same album or artist. Lower values make the playlist more varied but can cause a smaller AI curation pool when only a few albums are available for an artist, resulting in poor playlist quality or variety.

Playlist length and refresh frequency

Playlist length sets the target size after AI curation. A larger playlist size will result in a possibly larger curation pool, which results in a larger AI request and more reasoning. Refresh frequency controls whether the playlist stays static or rebuilds on a schedule.

Tip: start with the default similarity settings and check the pool size after "Find Similar Tracks". If the pool is small, lower the minimum score or add expansion rounds before adjusting anything else.
