Artist Radio

Artist Radio builds a playlist around a source artist. You choose the seed, decide how similar artists are found, and then shape the final mix with quality, diversity, and refresh settings.

Create a playlist in 5 steps
  1. 1 Choose a source artist. This is the seed for the radio. The more popular the artist is, the more likely it is to find similar artists automatically.
  2. 2 Decide whether to use ListenBrainz similarity. Leave it enabled to fetch similar artists automatically. Turn it off if you want to build the artist pool manually.
  3. 3 Set the similarity controls. The algorithm changes how similarity is calculated, and the minimum score controls how adventurous the recommendations are. Lower scores give a wider pool; higher scores stay closer to the source artist.
  4. 4 Refine the artist pool. Use the recommended artists that exist in your library, then add any extra library artists you want to include. This is the main control over the final sound.
  5. 5 Choose the final playlist shape. Set the playlist length, optional year range, minimum quality, diversity limits, and refresh frequency before creating the playlist.
What each option changes

Source artist

Sets the center artist of the radio. A more popular artist usually returns better results for automatic fetching.

ListenBrainz similarity

When enabled, MagicLists tries to find similar artists to your source artist matching your query using the ListenBrainz API. When disabled, the playlist is built only from the artists you pick yourself.

MusicBrainz ID fallback

Used only when the artist needs a Last.fm lookup or no ID is found for the specified artist in your library. It helps identify the artist correctly and does not change which tracks are selected for the playlist.

Algorithm and minimum score

The algorithm controls how similarity is measured. The score threshold controls how broad or narrow the recommendation pool becomes.

Similar artists and manual artists

These two fields decide which artists actually contribute tracks. This is the strongest influence on the final playlist.

Top tracks per artist

Adds top tracks for selected artists fetched from the Navidrome or Last.fm API. These tracks are included in the AI curation pool even when diversity limits are enabled.

Year range and minimum quality

Year range limits the eras in the candidate pool. Minimum quality filters out lower-bitrate or lower-bit-depth files before curation. This can cause a smaller AI curation pool when only lower-quality tracks are available, resulting in poor playlist quality or variety.

Diversity limits

Controls how many tracks can come from the same album or artist. Lower values make the playlist more varied but can cause a smaller AI curation pool when only a few albums are available for this artist, resulting in poor playlist quality or variety.

Playlist length and refresh frequency

Playlist length sets the target size after AI curation. Refresh frequency controls whether the playlist stays static or rebuilds on a schedule.

Tip: start with the default similarity settings, then adjust the artist pool and diversity limits first. Those usually have the biggest impact on the final result.
